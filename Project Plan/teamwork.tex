\section{Teamwork}

\subsection{File- and Version management}
There are multiple types of files that will be handled during the project. Each of these requires its own way of file and version management.
\\
Keeping code in one central place is essential to ensure smooth collaboration. Furthermore, having a good version control system makes it possible to go to previous versions if something breaks and see who wrote what. For this reason, we will be using \href{https://github.com/rbithray/CapstoneAI-Toxicity}{GitHub} to save all our code.
\\
To make sure anyone could use the code and reproduce the findings of the project, proper documentation is needed. This documentation will be saved, along with the code, on \href{https://github.com/rbithray/CapstoneAI-Toxicity}{GitHub}.
\\
The reports for this project will be written in \LaTeX using Overleaf. This both makes it possible for all group members to work together on the report at the same time and provides a version history feature.
\\
Miscellaneous documents will be saved to a private drive. As these documents are necessary during the execution of the project, it is essential that all team members have access to to these files.
